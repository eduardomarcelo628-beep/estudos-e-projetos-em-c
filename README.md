## 📌 Sobre o projeto

Este repositório reúne exercícios e pequenos projetos desenvolvidos durante meus estudos da linguagem C na graduação em Análise e Desenvolvimento de Sistemas (ADS).

O objetivo é praticar os fundamentos da programação, desenvolver o raciocínio lógico e acompanhar minha evolução por meio de exercícios práticos.

Os projetos estão organizados por assunto para facilitar a navegação e a consulta aos códigos-fonte.

---

## 📚 Projetos

### 01. Condicionais

Exercícios envolvendo estruturas condicionais e operadores lógicos.

| Projeto | Descrição | Conceitos praticados |
|---|---|---|
| `analisador_idade.c` | Classificação por faixa etária. | Variáveis, entrada de dados e condicionais. |
| `aprovacao_emprestimo.c` | Simulação de aprovação de empréstimo com base na idade e na renda. | Operadores relacionais, operadores lógicos e condicionais. |

### 02. Laços de repetição

Exercícios voltados à prática de contadores, acumuladores e estruturas de repetição.

| Projeto | Descrição | Conceitos praticados |
|---|---|---|
| `contador.c` | Calcula e exibe as etapas da soma dos números de 1 a 10. | `while`, contadores e acumuladores. |
| `soma_1a10.c` | Exibe os números de 1 a 10. | `for` e contadores. |
| `soma_1a100.c` | Calcula a soma dos números de 1 a 100. | `for` e acumuladores. |

### 03. Arrays e cálculos

Exercício envolvendo armazenamento de valores e operações matemáticas.

| Projeto | Descrição | Conceitos praticados |
|---|---|---|
| `media_calculo.c` | Calcula a média de cinco números armazenados em um array. | Arrays, `for`, `sizeof` e conversão de tipos. |

### 04. Jogos

Exercício de lógica de programação aplicado a um jogo de adivinhação.

| Projeto | Descrição | Conceitos praticados |
|---|---|---|
| `jogo_de_adivinhacao.c` | Permite ao usuário tentar descobrir um número secreto. | `do-while`, condicionais e contagem de tentativas. |

### 05. Menus e funções

Exercícios que exploram menus interativos, seleção de opções e organização do código.

| Projeto | Descrição | Conceitos praticados |
|---|---|---|
| `menu_de_opcoes.c` | Menu com opções para iniciar, carregar ou sair de um jogo. | `switch-case` e entrada de dados. |
| `menu_interativo.c` | Simulação de um sistema bancário com consulta de saldo, depósitos e saques. | Funções, `do-while`, `switch-case`, condicionais e operações aritméticas. |

## ▶️ Como executar os projetos

Para compilar e executar os programas, é necessário ter um compilador C instalado, como o GCC.

### 1. Clone o repositório

```bash
git clone https://github.com/eduardomarcelo628-beep/estudos-e-projetos-em-c.git
```

### 2. Acesse a pasta do projeto desejado

Por exemplo, para acessar os exercícios de condicionais:

```bash
cd estudos-e-projetos-em-c/01-condicionais
```

### 3. Compile o arquivo

Utilizando o GCC, execute:

```bash
gcc analisador_idade.c -o analisador_idade
```

### 4. Execute o programa

No terminal do PowerShell, no Windows:

```powershell
.\analisador_idade.exe
```

> **Observação:** os comandos de compilação devem ser ajustados de acordo com o nome do arquivo e a pasta do projeto escolhido.
